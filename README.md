# Tuna Sweeper 스토리 정리 작업본

> 원본: https://github.com/octopus7/extraction_shooter  
> 기준 커밋: `1ded0ce978b749bb19708c6e8cbf5df8e91e534d`  
> 수집 방식: GitHub API로 문서 파일만 가져옴. 저장소는 클론하지 않음.

## 목적

오래전에 작성된 스토리를 다시 검토하면서 현재 설정과 어긋난 내용을 제거하거나 수정하기 위한 로컬 작업본이다.

## 적용 원칙

1. **데모와 정규 버전을 서로 다른 연속성으로 분리**한다.
2. 현재 UE5 구현 퀘스트, `QuestDefinitions.json`, 런타임 스냅샷은 기준으로 사용하지 않는다.
3. 기존 안내 캐릭터 **캔봇은 두더지로 교체**한다.
4. 정규 버전은 구현 데이터가 아니라 `Docs/SSOT`의 기획 문서를 우선한다.
5. 확정되지 않은 내용은 임의로 채우지 않고 `미정` 상태를 유지한다.

## 문서 구성

### 공통 등장인물 기준

- [[01_등장인물_설정]]

루나는 인간과 같은 외형과 생활 기능을 가진 바이오닉 안드로이드이며, 충전식 기계 로봇처럼 묘사하지 않는다. 두더지는 지성을 가진 실제 동물로, 기지 2층 관제실에서 루나를 지원하며 자신의 진짜 정체는 끝까지 밝히지 않는다.

### 데모 버전

- [[데모/01_퀘스트_진행_트리]]
- [[데모/02_스토리_및_대화_대본]]
- [[데모/03_간소_대화_모드]]

데모는 **화장실 고장 → 취수 시설/배관 수리 → 참치캔 → 화장실 복구**로 끝나는 독립 단편이다. 데모 안에서는 화장실 수리가 실제 퀘스트다. 간소 대화 모드는 스킵 버튼을 찾는 번거로움 없이 각 장면을 루나 한 줄과 두더지 한 줄, 정확히 2대사로 진행한다.

### 정규 버전

- [[정규/01_퀘스트_스토리_SSOT]]
- [[정규/02_퀘스트_대화집]]
- [[정규/03_영상_모음]]
- [[정규/04_스팀_캡슐_후보]]

정규 버전은 **벙커 기상 → 제1생활권 확보 → 고급보안구역 → 최종보스 → 고급참치와 첫 식탁**으로 이어지는 본편이다. 정규 버전에서 화장실 수리는 실제 퀘스트가 아니라 반복 개그다.

## 우선 정리한 충돌

| 항목 | 충돌 | 이 작업본의 처리 |
|---|---|---|
| 안내 캐릭터 | 문서 전반이 캔봇 기준 | 두더지로 일괄 치환 |
| 화장실 수리 | 데모에서는 핵심 퀘스트, 정규에서는 비기능 개그 | 버전별 설정으로 분리하여 둘 다 유지 |
| M06~M08 게이트 | 정규 SSOT는 3개 중 2개 완료, 시뮬레이터 데이터는 3개 전부 완료 | 구현/시뮬레이터를 무시하고 SSOT의 **2개 이상** 채택 |
| 정규 상세 구조 | 보조 스토리 문서에 폐기된 시설 복구/포탈 직접 안내/구 명칭이 남아 있음 | 보조 초안은 가져오지 않고 SSOT 두 문서만 수록 |
| M18 진입 조건 | 신호기 사용 여부 미정 | 미정 유지 |
| M19 고급참치 | 획득처 미정 | 미정 유지 |

## 다음 검토가 필요한 부분

- 정규 대사에는 `제목`, `서사`, `UI`, `퀘스트 실패`, `본편`, `밸런스 패치`, `엔딩` 같은 제4의 벽 개그가 많다. 유지 여부를 별도로 결정하는 편이 좋다.
- 정규 M18의 보스구역 진입 신호기와 M19의 고급참치 획득처는 아직 설계 결정이 필요하다.
- 정규 퀘스트는 수집 아이템 수가 많아 스토리 동기보다 체크리스트처럼 느껴질 수 있다. 이후 검토에서 각 퀘스트의 감정적 이유를 보강할 필요가 있다.
